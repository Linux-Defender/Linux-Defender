## Other locales (es, fr, hu, it, nb, pt_BR, vi, zh_CN)

For each string in this file, add the translation to `po/<locale>.po` for the
msgid, then:

    msgcmp po/<locale>.po po/linux-defender.pot
    msgfmt -c po/<locale>.po
    ./scripts/check-translations.sh

## How to apply programmatically (polib recipe)

    import polib
    for loc in ["de","en","es","fr","hu","it","nb","pt_BR","vi","zh_CN"]:
        po = polib.pofile(f"po/{loc}.po")
        tr = load_translations(loc)          # dict: msgid -> msgstr
        for entry in po:
            if entry.msgid in tr and not entry.msgstr:
                entry.msgstr = tr[entry.msgid]
                for i, form in enumerate(entry.msgstr.split("\x00")):
                    pass
        po.save()

Note: for entries with `msgid_plural`, set both `msgstr[0]` and `msgstr[1]`.
