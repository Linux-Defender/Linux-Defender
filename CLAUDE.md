# CLAUDE.md

The AI-assistant guide for this repository lives in [`AGENTS.md`](AGENTS.md). That file is the canonical, tool-neutral source: git hooks and CI enforce the same rules in Claude Code, OpenCode (Open Code), Codex, Aider, Cursor, Continue, and Zed — or any other assistant. Claude Code is listed first because it is the most common, not because it is privileged.

**Edit `AGENTS.md`, not this file.** This stub exists only so Claude Code's CLAUDE.md auto-discovery still finds guidance. Also read [`AI-ENFORCEMENT.md`](AI-ENFORCEMENT.md): the canonical rules file with skill-style frontmatter. It is injected at `SessionStart`, re-reminded on `UserPromptSubmit`, and no adapter duplicates its text. Before saying "done", run `bash scripts/check-all.sh` and fix every failure; `.claude/settings.json` runs it automatically on every `Stop`. `scripts/check-ai-enforcement-wiring.py` verifies this wiring. An optional plugin package at `.claude/plugins/linux-defender-enforcement/` adds a pointer skill, a capture command, and a reviewer agent; it deliberately declares no hooks, so the always-on settings hooks remain the only enforcement path.

Project-local coding-agent skills live in `.agents/skills` (`accessibility`, `linux-defender-gettext`, `linux-defender-parity`, `linux-defender-integrations`, `linux-defender-enforcement`, `rust-best-practices`, `vercel-react-best-practices`); Claude Code and other assistants can use them directly. Use `linux-defender-parity` for any "audit everything / check parity / find dead or stale code / verify sync" task and `linux-defender-integrations` for native/desktop/host integrations. Both point to `AGENTS.md` and `docs/clamui-fork/STATUS.md` as the canonical records.

## Tools and commands (quick pointer)

`AGENTS.md` is the full tool/command inventory; the phrase **"yk the drill"** activates the exhaustive review via `/deep-audit` (or `./scripts/deep-audit.sh`, with `--quick`/`--fleet`), also exposed read-only as MCP `ld_deep_audit`. The essentials are: `./scripts/update-all.sh` to regenerate and verify, `bash scripts/check-all.sh` for static checks, `bash scripts/audit-consistency.sh` for the full audit, `./scripts/capture-all.sh` for every visual surface (`scripts/capture-app-window.sh` for the real WebKitGTK window), `bun run --cwd desktop tauri dev` for the real app, and the read-only `linux-defender-assist` MCP tools (`ld_repo_status`, `ld_support_parity`, `ld_helper_probe`, `ld_tray_probe`, `ld_desktop_capture`, `ld_translation_candidates`, `ld_translation_suggest`, `ld_online_preflight`, `ld_deep_audit`). Never dispatch Release or create a `v*` tag; those stay human decisions.
