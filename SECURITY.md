# Security Policy

## Report a vulnerability

**Do not report vulnerabilities in public issues.** Use [GitHub's private vulnerability reporting](https://github.com/Linux-Defender/Linux-Defender/security/advisories/new) when it is enabled for this repository. If GitHub reports that private reporting is unavailable, contact the repository maintainers privately before sharing technical details; do not publish an exploit or sensitive proof of concept.

Include the affected commit or version, impact, reproduction steps or proof of concept, and a suggested mitigation when known. The project is a development snapshot and does not yet have a published security-response SLA or signed release packages.

See the detailed [security guide](website/src/content/docs/docs/contributing/security.md) for scope and safe-use guidance.
